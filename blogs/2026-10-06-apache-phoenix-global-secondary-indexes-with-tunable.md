Apache Phoenix provides an open-source SQL interface over Apache HBase, combining the power of NoSQL horizontal scaling and sharding with SQL simplicity for low-latency and high-throughput OLTP operations on petabyte-scale data. Phoenix complements HBase by providing capabilities such as Global Secondary Indexes (GSIs), Atomic and Conditional updates, change data capture (CDC) streams, Updatable views, and multi-tenancy support across tables, indexes, and views. Furthermore, it supports server-side push-down execution for complex OLAP joins and grouping operations.
